# Gitty

A minimal, dark-themed blog platform built with Angular 17+ and deployed on GitHub Pages. Write in Markdown, publish via GitHub API, and enjoy a clean, distraction-free reading experience.

## About

This is my personal blog where I share thoughts on development, design, and life. Built with a focus on simplicity, performance, and minimalism.

## Features

- **Minimal Design**: Dark AMOLED theme with clean typography
- **Markdown Support**: Write posts in Markdown with frontmatter
- **Tag Filtering**: Filter posts by tags with a sidebar navigation
- **GitHub Pages**: Fully hosted on GitHub Pages with automatic deployment
- **No Backend**: Repository acts as the database
- **CLI Tool**: Upload posts directly via GitHub API

## Tech Stack

- Angular 17+ (Standalone components)
- TypeScript
- Markdown (ngx-markdown)
- GitHub Pages
- GitHub Actions

## Posts

Browse all posts on the [Posts](/posts) page, or filter by tags using the sidebar.
